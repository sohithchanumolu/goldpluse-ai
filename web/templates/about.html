📈 GoldPulse AI

GoldPulse AI is an AI-powered gold market intelligence platform designed for Indian investors and jewellery buyers. It combines real-time gold pricing, historical tracking, automated analysis, and AI-generated market insights into a single dashboard.

🚀 Features

  • Daily 24K and 22K gold price tracking
  • USD/INR exchange rate integration
  • Historical gold price database
  • Interactive trend charts
  • AI-generated market analysis
  • Telegram notifications and alerts
  • FastAPI-powered dashboard

⚙️ Technology Stack

  • Python
  • FastAPI
  • SQLAlchemy
  • SQLite
  • Plotly
  • Google Gemini
  • Telegram Bot API
  • HTML & CSS

🏗️ System Architecture

Gold Price API → Data Collection

Data Collection → SQLite Database

Database → Dashboard + History

Gemini AI → Market Analysis

Analysis → Website + Telegram Alerts
